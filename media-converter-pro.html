01 / OVERVIEW

A practical full-stack workflow

Media Converter Pro connects a responsive browser interface to a Python backend. The backend validates the submitted URL, creates a task, delegates media processing to yt-dlp and FFmpeg, and returns a task-specific download when processing succeeds.

FEATURE / 01

MP4 video output

Choose best available or a target resolution up to 1080p when the source provides it.

FEATURE / 02

MP3 audio output

Extract audio and encode it to MP3 with a selectable bitrate.

FEATURE / 03

Live progress

WebSocket updates with a REST status endpoint as a fallback.

FEATURE / 04

Responsive interface

Compact form controls, progress feedback and clear success/error states.

FEATURE / 05

Task-specific files

Each task has its own output directory and a task-ID download route.

FEATURE / 06

Input validation

Accepts supported YouTube and Instagram hostnames and validates requested output settings.

02 / ARCHITECTURE

How the system works

Browser UI→FastAPI API→yt-dlp→FFmpeg→Download

JavaScript sends a conversion request to /convert. The API returns a task ID. The interface listens to /ws/{task_id} for progress and can poll /status/{task_id} if the socket is unavailable. Completed files are served through /download/{task_id}.

04 / ENGINEERING NOTES

Reliability and responsible use

The project includes bounded task concurrency, URL and format validation, task-scoped output folders, status polling fallback, clear failure messages, and best-effort cleanup of older output folders. In-memory tasks are intended for a single-process demo and are not a durable distributed job queue.

Use only for media you own or have permission to download. Respect the source platform's terms and copyright. Private or login-gated media is not supported by default.
05 / DEPLOYMENT

Designed for a Python host

The interactive converter requires a Python ASGI host and FFmpeg installed on the server. A static portfolio host such as GitHub Pages can display this case-study page, but it cannot run the FastAPI conversion backend. Deploy the backend separately and connect the portfolio's project link to this page or to the live application.
